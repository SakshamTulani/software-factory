# Architecture decision records

Named `YYYY-MM-DD-<slug>.md`, never numbered, so ADRs written on parallel branches can't collide. Never edited after acceptance. A changed decision gets a new ADR that supersedes the old one. Copy [_template.md](_template.md) and add a row here, in date order, in the same commit.

Decisions the factory made for every project (TanStack Query as the store cache, the three-tier module layout) live in the factory's own ADRs. This folder holds this project's decisions.
